# src/camera — Non-Obvious Type Decisions

- **`BambuBinaryCameraStream::with_max_frame_size()`** overrides the default 10MB frame-size cap (`CAMERA_FRAME_MAX_SIZE`). Embedded/Embassy callers should lower it to match their actual buffer budget — 10MB can exceed a bare-metal target's entire SRAM, and allocation failure there hits the uncatchable `alloc_error_handler`, not a `Result`. `authenticate()` returning `Ok(())` only confirms the handshake packet was written — a rejected access code surfaces later as `ConnectionReset` from `read_next_frame()`, indistinguishable from a network blip.
- **`camera::rtsps::build_rtsps_url`** returns `Result<String, Error>`, not `String` — validates `access_code` is non-empty ASCII alphanumeric before interpolating into the URL. `rewrite_rtsp_request_uri` only rewrites the request-line URI text, not the Digest `Authorization` header.
