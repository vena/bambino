# src/camera — Non-Obvious Type Decisions

- **`BinaryCameraStream::with_max_frame_size()`** overrides the default 10MB frame-size cap (`CAMERA_FRAME_MAX_SIZE`). Embedded/Embassy callers should lower it to match their actual buffer budget — 10MB can exceed a bare-metal target's entire SRAM, and allocation failure there hits the uncatchable `alloc_error_handler`, not a `Result`. `authenticate()` returning `Ok(())` only confirms the handshake packet was written — a rejected access code surfaces only on the next frame read, as `ConnectionReset` if the printer closes the socket, `TimedOut` if it stays silent and the read has a real timer (`PrinterClient::read_camera_frame`), or an indefinite hang if it stays silent under timerless `read_next_frame()`. Each is indistinguishable from a network fault. The mock (`tests/integration/common/mock_camera.rs`) models only the close case.
- **`camera::rtsps::build_rtsps_url`** returns `Result<String, Error>`, not `String` — validates `access_code` is non-empty ASCII alphanumeric before interpolating into the URL. `rewrite_rtsp_request_uri` only rewrites the request-line URI text, not the Digest `Authorization` header.
