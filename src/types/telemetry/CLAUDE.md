# src/types/telemetry — Non-Obvious Type Decisions

- **Temperature fields** are `Option<f64>` — the wire sends both integers (H2D) and floats (P1S/A1). Bed and nozzle targets arrive as separate `_target_temper` fields (never composite-packed). Use `unpack_temperature()` only for `chamber_temper` on models with active chamber heaters, for `ExtruderInfo.temp` on IDEX platforms, and (via `unpack_bed_telemetry()`) for `device.bed.info.temp` on new-gen models with composite-packed bed telemetry.
- **`DeviceTelemetry`** appears at two wire locations (see its doc comment for which triggers which). `TelemetryReport::device()` checks top-level `device` first, then `print.device` — prefer it over manually checking both.
- **`PrinterTelemetry::is_ethernet_active()`** reads `print.net.conf` bit 0 (BUG-110) — the earlier `home_flag` bit-18 heuristic was confirmed wrong (both BambuStudio and OrcaSlicer decode that bit as `is_support_prompt_sound_detection`). `is_ethernet_active_via_wifi_signal()` (checks `wifi_signal == "-90dBm"`) remains as a fallback for firmware that doesn't send `net.conf`.
- **`ExtruderInfo.temp`** uses the same composite packing as `chamber_temper` (values > 500 encode target << 16 | actual). Use `ExtruderInfo::temperatures()` to decode. The `ExtruderCollection.state` bitmask encodes extruder count (low 4 bits) and active index (bits 4–7); use `active_extruder_index()` / `extruder_count()`.
- **`AmsTray.id`** is `String` (wire sends `"0"`, not `0`). **`CtcInfo.temp`** is `u32` (composite-packed integers, not floats).
- **`AmsUnit.info`** is `Option<String>` — wire sends hex-encoded bitmask (e.g. `"11002103"`). Parse with `u64::from_str_radix(s, 16)`. Bits 0–3 = AMS type, bits 4–7 = dry_status, bits 8–11 = extruder assignment (0=right, 1=left, 0xE=uninitialized), bits 22–23 = dry_sub_status, bits 24–27 = `bind_switch_in` (four bits, not two — BUG-136; `0`=In-B, `1`=In-A, anything else = not bound; decode via `filament_switch_inlet()`), bits 30–31 = remain-estimate version.
- **`BedTelemetry`** (`device.bed`) uses the same composite packing as `chamber_temper` — `bed.info.temp` values > 500 encode `(target << 16) | actual`. Present on H2/P2/X2 models; old-gen models use `bed_temper` / `bed_target_temper` instead.
- **`stg_cur`/`stg`** decode to `PrintStage` (`stage.rs`), but `stg_cur` must stay behind the [REF-MQTT-IDLEBUG] `gcode_state` gate — A1/P1 report `0` ("printing") while idle. `PrinterTelemetry::current_stage()` applies that gate and is the default; `current_stage_ungated()` is the escape hatch. Typing the value makes the gate *more* important, not less: a `PrintStage::Printing` in a UI reads as authoritative where a bare `0` did not. Idle mid-run is normal and is not completion — `stg_cur` reads idle for the tail of a run after the last queued stage ends. `stg` needs no gate. Idle is `-1` on X1 and `255` on P1; both normalize to `PrintStage::Idle`.
- **`vir_slot`** is separate from `vt_tray` — IDEX models send `vir_slot: Vec<VirtualTray>` (one per extruder), while single-nozzle models send `vt_tray: VirtualTray`. Both use the same `VirtualTray` schema.
