# src/ftps — Non-Obvious Type Decisions

- **Path validation has two halves, and only one applies to inbound names** (`src/ftps/protocol.rs`). `validate_ftp_path_bytes` rejects every C0 control byte and DEL: CR/LF would inject a second command, and other control bytes smuggle terminal escapes into logs. `validate_ftp_path` adds the command-argument rules, rejecting a `..` segment and a final segment starting with `-`; every path-taking `FtpsClient` method calls it. `parse_unix_listing` applies **only** the bytes half to server-supplied names and skips entries that fail it. Running the full check there once dropped legitimately named files such as `-timelapse.mp4` from every listing; `test_leading_dash_filename_survives_listing` guards it.
- **`FtpsClient::connect` has an opt-out from its TLS-1.2-enforcement check**: `tls_version_check: TlsVersionCheck` (`PrinterClient::with_ftps_allow_unverified_tls_1_2(true)` sets it). `TlsVersionCheck::Bypass` skips the `negotiated_version == Some(Tls12)` check entirely. Every backend reports the negotiated version (embassy since `mbedtls-rs` 0.3, #289), so the check passes wherever the printer negotiates 1.2; this bypass is the escape hatch for a peer that insists on 1.3 on `esp-idf`/`embassy`, neither of which can cap the maximum version. Safe despite being fail-open: `upload_file`'s `SIZE` recheck and `download_file`'s acceptance of both `226` and the documented `426` close-race reply independently catch a truncated transfer regardless. `list_directory` is the weaker case and the justification does not extend to it unchanged — a listing has no `SIZE` to compare against, so its 426 tolerance is backed only by a line-framing check (a 426 whose payload is empty or doesn't end on a line terminator is rejected). A truncation landing exactly on a line boundary still passes silently there; don't cite the SIZE recheck as covering LIST. Default `false`. Only `tokio` has a real cap (`TlsVersions::Tls12Only` on `TokioTlsConnector::verified`/`unverified`); `esp-idf` has no upstream knob for it and `embassy` sets only `min_version`.
