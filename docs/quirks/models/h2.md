- [`H2_BED_TEMP_MAX`](#h2_bed_temp_max) - Bed temperature ceiling (°C) shared across the H2 family, per `MODEL_MATRIX.csv`'s Max Build Plate Temperature row.
- [`H2_CHAMBER_TEMP_MAX`](#h2_chamber_temp_max) - Chamber temperature ceiling (°C) shared across the H2 family, per `MODEL_MATRIX.csv`'s Max Chamber Temperature row.
- [`H2_DUAL_Z_MAX`](#h2_dual_z_max) - Z depth (mm) shared by H2D, H2D Pro, and H2C — does not vary by active nozzle, per `MODEL_MATRIX.csv`'s Build Volume row.
- [`H2_NOZZLE_TEMP_MAX`](#h2_nozzle_temp_max) - Nozzle temperature ceiling (°C) shared across the H2 family, per `MODEL_MATRIX.csv`'s Max Hot End Temperature row.
